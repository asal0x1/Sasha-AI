# Sasha AI

Sasha AI is an intelligent Python-powered virtual assistant designed to automate desktop tasks using voice commands, wake-word activation, and real-time intent recognition. The assistant remains inactive until a wake word is detected, creating a more natural and interactive AI experience.

Features
Wake-word activation system (Hey Sasha, Sash, Sasha)
Intelligent intent recognition
Greeting responses
Current time detection
Open websites like YouTube and Google
Automated scrolling controls
Stop scrolling command
Exit/shutdown command support
Multithreading for smooth background execution
Real-time command processing
Technologies Used
Python
Threading
Webbrowser Automation
Speech/Command Recognition
Intent-Based AI Logic
